# OctaPixel (Made for my buddies)
**"An extremely simple site for drawing maps and room diagrams! Based on pixel art."**

## OVERVIEW
"OctaPixel (Octahedron Pixel) is a site where you can choose different shapes and draw anything you want with them. But originally planned for drawing diagrams of Rooms!"

## AMBITIONS
**1. Add functioning js (script.js)**
**2. Add functioning css (style.css)**
3. Add the ability to save to the gallery with one button

## SCREENSHOTS
none

## HOW IT WORKS
**For the file-split version:**
1. When you enter the index.html, **HTML includes two files: script.js, style.css**
2. (script.js) **is responsible for drawing a grid of cells (on canvas), and for the drawing itself.**
3. (style.css) **responsible for cosmetics, partly for grid and drawing.**
**For compressed:**
**Everything is the same as in the file-split version, but everything works in one html file!**
